# lib-go

> A library of reusable code for my personal Golang projects.

## 🎯 Motivation

Golang is my primary language of choice when developing personal projects that requires a backend. 

There are some common patterns and code that I find myself repeating across all my projects, such as setting up logging, database migrations, various utilities to work with time, pointers, etc.

The purpose of this library is to have those common code in one place, so I can easily reuse it across all my projects. Having this library also forces me to think about creating reusable code and abstractions, which is a good practice in software development.

## 📋 What is included

- [`cache`](cache/README.md): Key-value `Cache` abstraction with per-entry expiration, plus `InMemory` and `Noop` implementations.
- [`env`](env/README.md): Helpers for reading typed values from environment variables.
- [`events`](events/README.md): Synchronous, in-process event `Bus` for decoupled communication between components.
- [`mailer`](mailer/README.md): `Mailer` abstraction for sending email, plus `SMTP`, `Noop` and `Fake` implementations.
- [`nullable`](nullable/README.md): Generic `Value` type representing a value that may be null, useful when working with databases that allow null columns.
- [`pagination`](pagination/README.md): Types and helpers for offset-based and cursor-based pagination.
- [`ptr`](ptr/README.md): Generic helper functions for working with pointers, such as `Ptr` and `Val` to create and dereference them.
- [`sorting`](sorting/README.md): Types for validated `ORDER BY` clauses in repository queries.
- [`timeutil`](timeutil/README.md): Time-related abstractions — `Clock`, `Sleeper` and `Ticker` — to write deterministic, fast tests for time-dependent code.
- [`uow`](uow/README.md): Unit of Work interfaces for managing cross-repository transactions.

## 🚀 Getting started

### Installation

```shell
go get github.com/brpaz/lib-go
```

### Usage

Each package includes a `README.md` file generated by [Gomarkdoc](https://github.com/princjef/gomarkdoc), with includes documentation and examples for that package.

## 🧑‍💻 Development Quick start

This project uses [Devenv](https://devenv.sh/getting-started/) as the development environment. Devenv allows to provide an isolated development environment with all the necessary tools and dependencies installed, without polluting the host machine.

### Prerequisites

- [Devenv](https://devenv.sh/getting-started/) 
- [Direnv](https://direnv.net/)

### Quick start

- Clone the repository:

```shell
git clone https://github.com/brpaz/lib-go
cd lib-go
```

- Enter the development environment:

```shell
direnv allow
```

- Run tests:

```shell
task test
```
